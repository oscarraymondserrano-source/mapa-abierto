# Recursos de audio

| Archivo | Origen | Licencia |
|---|---|---|
| `Musica/MapaAbierto_synthwave_bed.wav` | Pista original sintetizada para este proyecto (`_build/audio.py`) | Propia: uso libre en el canal, sin Content ID |
| `SFX/whoosh.wav`, `SFX/sting_marca.wav` | Efectos sintetizados para este proyecto | Propia |
| Locución guía (en cada `VIDEO_XX/Locucion/`) | Sintetizador Piper con la voz `es-carlfm-x-low` | Dataset de dominio público (ver `LICENCIA_voz_guia_TTS_carlfm.txt`) |

La locución guía es de baja fidelidad (16 kHz) y su acento no está garantizado como peninsular: sirve para cuadrar tiempos. Para publicar, usa la voz definitiva (ver `ficha_de_voz.md` de cada vídeo).
Mezcla recomendada: voz −14 LUFS integrados; música −22 dB por debajo de la voz con ducking; efectos −18 dB.
